## 3. Numerical Analysis Lab
**Repository:** [nadin54/Numerical_analysis_app](https://github.com/nadin54/Numerical_analysis_app)

**Language:** Python (100%)

**Description:**  
A desktop application for teaching and exploring numerical analysis methods. Provides a graphical interface to solve and visualize classic numerical problems with pure computation code separated from UI logic.

**Key Features:**
- Root finding: bisection, Newton–Raphson, secant methods (with automatic bracket discovery)
- ODE solvers: Euler and Heun's method with step tables
- Numerical integration: trapezoidal, Simpson's 1/3 and 3/8 rules
- Curve fitting (least-squares): linear, quadratic, cubic, power, exponential families
- Interpolation: Lagrange, Newton forward/backward differences
- Safe expression parsing using SymPy
- Step-by-step computation tables and visualization

**Technologies:**
- Python 3.8+
- CustomTkinter (modern Tkinter wrapper)
- NumPy, SciPy, SymPy (numerical & symbolic math)
- Matplotlib (plotting)

**Core Competencies:**
- Numerical algorithm implementation
- Scientific computing with NumPy/SciPy
- Symbolic mathematics with SymPy
- GUI design for technical applications
- Mathematical expression parsing and validation
- Clean code architecture (separation of concerns: methods.py, ui.py, parsing.py)
